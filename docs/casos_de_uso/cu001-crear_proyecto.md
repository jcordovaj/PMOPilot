# Caso 1: Crear Proyecto

```text
Usuario escribe en chat o presiona boton `Crear proyecto`
↓
Bootstrap Agent detecta activacion del flujo por boton o intencion por chat
↓
Inicia flujo Nuevo proyecto
↓
Solicita informacion basica y aclaraciones
↓
Crea o conecta con Repositorio GitHub
↓
inicializa un objeto Project en bbdd para registar su ciclo de vida y artefactos relacionados
↓
crea README inicial con datos obtenidos del usuario
↓
Primer Workflow
↓
Dashboard y herramientas anexas
↓
PMO del Proyecto lista para que el usuario comience su desarrollo con su herramienta favorita

```
